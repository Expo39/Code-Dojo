# Discussion questions: m06_testing

Questions for a discussion drill: answer out loud, at your level, with a concrete
example; the tutor follows up (why? when would you not?) and judges against the read-first sources (track
README). No answers here on purpose.

1. How does Django keep tests from affecting each other, and when does that stop working?
2. What is a good test for a view: the status, the content, the database, or all of them?
3. How do you catch a new N+1 query before it reaches production?
4. Factories or fixtures for test data: when do you choose each?
5. How do you test code that sends email, calls an outside API or depends on the time?
6. What does a migration test look like, and is it worth having?
