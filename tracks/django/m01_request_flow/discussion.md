# Discussion questions: m01_request_flow

Questions for a discussion drill: answer out loud, at your level, with a concrete
example; the tutor follows up (why? when would you not?) and judges against the read-first sources (track
README). No answers here on purpose.

1. Trace a request from the browser to your view and back. Where can you add behaviour on the way in and on the way out?
2. Why use `reverse()` and named URLs instead of writing paths by hand?
3. What is the difference between a project and an app, and when do you create a new app?
4. What does middleware order change? Give an example where swapping two middleware changes behaviour.
5. Which HTTP methods are safe, which are idempotent, and why does it matter for a view?
6. What does `{{ value }}` do with HTML in `value`, and when would you turn that off?
7. What is the difference between static files and media files, and who serves each in production?
