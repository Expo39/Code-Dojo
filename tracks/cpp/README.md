# C / C++ (optional placeholder)

Shows where a C/C++ track would plug in. It is not part of any plan unless a learner chooses
it in their own `progress/PLAN.md`. To build it, add a `track.json` (see `docs/TRACKS.md`) and
ask the tutor to design and generate the modules.

A sensible outline, for after Python fundamentals and data structures:

1. C basics: types, pointers, arrays, strings, structs, `malloc`/`free`, undefined behaviour, `gdb`, `valgrind`.
2. Modern C++ (17/20): references, RAII, classes, the STL, smart pointers, move semantics, templates basics.
3. Tooling: CMake, GoogleTest (`ctest` as the track's test command), sanitizers, clang-format.
