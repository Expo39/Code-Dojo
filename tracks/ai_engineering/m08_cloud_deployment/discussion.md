# Discussion questions: m08_cloud_deployment

Questions for a discussion drill: answer out loud, at your level, with a concrete
example; the tutor follows up (why? when would you not?) and judges against the read-first sources (track
README). No answers here on purpose.

1. How would you expose a model-backed feature as a service? What do you validate and how do you stream?
2. Where do API keys live in development, in a container and in the cloud, and who can read them?
3. What changes when you containerise a service that needs a GPU?
4. Calling a provider's API directly or through a cloud's managed service: how do you decide?
5. What does an inference server such as vLLM do that a plain script does not?
6. How would you size a GPU for a 7-billion-parameter model, and what makes the estimate wrong?
7. How do you stop a cloud experiment from producing a surprise bill?
8. Name three ways to make inference faster or cheaper and what each costs in quality or complexity.
