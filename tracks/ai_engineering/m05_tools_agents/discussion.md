# Discussion questions: m05_tools_agents

Questions for a discussion drill: answer out loud, at your level, with a concrete
example; the tutor follows up (why? when would you not?) and judges against the read-first sources (track
README). No answers here on purpose.

1. What is the difference between a workflow and an agent? When is an agent not worth it?
2. Name the common workflow patterns and give a use for two of them.
3. Walk through an agent loop. Where can it go wrong, and how do you stop a runaway agent?
4. What makes a good tool for an agent, and what makes a bad one?
5. What is MCP, what problem does it solve, and what are hosts, clients and servers?
6. What is context engineering, and how does it differ from prompt engineering?
7. Framework or plain API calls: when would you use each?
8. Design an agent that triages support tickets: tools, limits, human checks.
9. When would you split an agent into several, and what do you pay for it?
10. How does agentic RAG differ from a fixed RAG pipeline, and when is the fixed pipeline the better choice?
11. What does planning add to an agent, and how does a plan go wrong?
