# Lessons: m04_rag

Concepts in this module that a `teach me` lesson can cover: the RAG pipeline, citations, debugging RAG, RAG versus long context.

Most lessons in this track start from a source you read yourself (the track README, "How lessons work"),
then a recall in your own words, then the tutor's questions; a lesson runs the five PRIMM steps
(`docs/CHECKLISTS.md`, section 2) where code behaviour is the point. Code you type in a lesson goes in
your own folder:

```text
workspace/ai_engineering/m04_rag/primm/<topic>.py
```

`python dojo.py primm m04_rag <topic>` creates that folder and an empty lesson file. The examples are always
on a different problem from the exercises in this module. Lesson files are not exercises: the tracker
ignores everything under `primm/`. Reference explainers for some topics are in `explainers/`.
