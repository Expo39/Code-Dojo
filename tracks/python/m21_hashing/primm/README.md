# PRIMM lessons: m21_hashing

Concepts in this module that a `teach me` lesson can cover: complexity basics, hash maps and sets.

Theory: Big-O notation (counting steps as the input grows), and how a hash table finds a key in about one step. The tutor offers a short theory lesson on it before the module's first exercise.

A lesson runs the five PRIMM steps (`docs/CHECKLISTS.md`, section 2): predict a worked
example, run and investigate it, modify it, then make three tiny functions. You type all of
it yourself, in your own folder:

```text
workspace/python/m21_hashing/primm/<topic>.py
```

`python dojo.py primm m21_hashing <topic>` creates that folder and an empty lesson file.
The examples are always on a different problem from the exercises in this module, so a
lesson never gives an exercise away. Lesson files are not exercises: the tracker ignores
everything under `primm/`.
