# PRIMM lessons: m08_python_model

Concepts in this module that a `teach me` lesson can cover: names vs objects, mutability, aliasing, copies, scope, late binding.

A lesson runs the five PRIMM steps (`docs/CHECKLISTS.md`, section 2): predict a worked
example, run and investigate it, modify it, then make three tiny functions. You type all of
it yourself, in your own folder:

```text
workspace/python/m08_python_model/primm/<topic>.py
```

`python dojo.py primm m08_python_model <topic>` creates that folder and an empty lesson file.
The examples are always on a different problem from the exercises in this module, so a
lesson never gives an exercise away. Lesson files are not exercises: the tracker ignores
everything under `primm/`.
